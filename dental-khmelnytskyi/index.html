«Емаль»: блокова тема WordPress без конструкторів

Сайт стоматологічної клініки, який адміністратор редагує в стандартному редакторі WordPress. Вся верстка в theme.json і патернах, без Elementor і без жодного плагіна.

Відкрити в WordPress Playground Завантажити тему (zip)

Playground запускає WordPress прямо в браузері: встановлює тему, створює 11 сторінок і меню. Перше завантаження 15-30 секунд. Ви одразу залогінені як адміністратор і можете відкрити редактор сайту.

Що всередині теми

  • theme.jsonПалітра, типографіка з fluid-розмірами, відступи, стилі кнопок і посилань. Локальні шрифти Lora і Onest.
  • Шаблони і частиниfront-page, page, page-wide, index, single, 404; шапка і футер як патерни з динамічними посиланнями.
  • 21 патернПерший екран, переваги, послуги, лікарі, ціни, FAQ, запис, заклик до дії і готові сторінки.
  • Дані в одному місціNAP, графік, ціни і FAQ у inc/data.php. Міняєте телефон один раз, і він оновлюється всюди, разом зі схемою.
  • Локальне SEO без плагінаСвої title і description для кожної сторінки, Open Graph, Dentist JSON-LD, BreadcrumbList, FAQPage.
  • Запис онлайнФорма з вибором послуги, лікаря і часу, перевіркою полів і станом успіху. Закріплена кнопка дзвінка на мобільному.

Сторінки демо

Головна · Послуги (Імплантація, Лікування карієсу, Професійна гігієна) · Лікарі · Ціни · Райони (Виставка, Озерна) · Контакти. Сторінки створює функція emal_demo_setup() під час активації теми, тому та сама тема розгортається і на звичайному хостингу.

Blueprint для Playground

{
  "landingPage": "/",
  "steps": [
    { "step": "login", "username": "admin" },
    { "step": "installTheme",
      "themeData": { "resource": "url", "url": ".../dental-khmelnytskyi/emal.zip" },
      "options": { "activate": true } },
    { "step": "runPHP",
      "code": "<?php require_once '/wordpress/wp-load.php'; wp_set_current_user(1); emal_demo_setup();" }
  ]
}

Повний файл: blueprint.json. Код теми: GitHub.
